## 📋 نبذة عن المشروع

**BloodConnect** تطبيق إنساني يربط بين المتبرعين بالدم والمرضى المحتاجين: سجّل كمتبرع، حدّد فصيلة دمك ومحافظتك، وكن بطلاً ينقذ حياة. سهّل عملية العثور على المتبرع المناسب في اللحظة الحرجة.

</div>

## 📋 About

**BloodConnect** is a humanitarian app that connects blood donors with patients in need: register as a donor, specify your blood type and governorate, and become a lifesaver. Find the right donor at the critical moment.

## ✨ Features | المميزات

- 🩸 Donor registration with blood types | تسجيل المتبرعين بفصائل الدم
- 🔎 Browse available donors by type/governorate | البحث عن متبرعين حسب الفصيلة والمحافظة
- 🏥 Hospital / donor roles | أدوار المستشفى والمتبرع
- 📱 Fast & simple Arabic-first UI | واجهة عربية سريعة وسهلة
- 📶 Connectivity gate | التحقق من الاتصال

## 🛠 Tech Stack

`Flutter` · `Firebase` · `Material 3`

## ⬇️ Download & Run | التحميل والتشغيل

```bash
git clone https://github.com/Zuhairibrahim/bloodbank.git
cd bloodbank
flutter pub get
flutter run
```
